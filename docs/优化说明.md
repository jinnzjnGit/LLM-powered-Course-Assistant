# Python课程学习助手代码优化说明

本次把教师演示原型整理为可测试、可分模块教学的本地个人/小组应用。保留资料答疑、章节总结、练习测验、学习记录和复习计划五个入口，优先修复会污染资料、评分和记录的问题。没有把当前应用包装成班级多人平台。

## 结构调整

```text
app.py                         Streamlit启动入口
learning_assistant/
  ui.py                        页面编排及五个独立render函数
  config.py                    项目路径、配置、容量限制
  llm.py                       模型连接、超时、提示词加载、错误提示
  model_service.py             问答、总结、出题、批改、规划
  materials.py                 PDF解析、OCR、内容身份
  retrieval.py                 保留缩进的分段、BM25、索引缓存
  validation.py                模型题目、分数、引用校验
  quiz_state.py                资料切换、试卷身份、答案提交快照
  storage.py                   SQLite事务、连接关闭、增量迁移
prompts/                       五个独立system提示词
tests/                         离线业务测试、PDF与页面集成测试
scripts/check_environment.py   本地环境检查，不调用远程模型
setup.ps1 / start.ps1          安装和本地启动
requirements-lock.txt          本次Windows/Python 3.12环境快照
```

业务模块不依赖Streamlit会话，除PDF模块外，大部分业务可以仅用Python标准库测试。界面每次重跑调用main，不依靠导入时副作用。UI仍使用直接的表单代码，便于基础薄弱学生阅读，没有引入额外Web框架或Agent框架。

## 修复及新的行为

| 原问题 | 新行为 | 检查方式 |
|---|---|---|
| 连续空格被压缩，破坏Python代码 | 分段保留空格和制表符，校验窗口参数 | 嵌套Python示例保持一致且可编译 |
| 同名同大小PDF沿用旧内容 | 文件签名使用SHA-256；页与片段保留内容ID | 同名等长但内容不同的文件签名不同 |
| 同名文件混合成一份资料 | 同一批拒绝同名PDF | 同名文件输入测试 |
| 模型题目校验不完整 | 整批检查题数、题型、非空文本、选项、答案、页码和重复题干 | 非法题目与部分题目均拒绝 |
| 漏批、重复题号和隐式分数转换 | 全部题号必须恰好出现一次，分数必须是0—5整数 | 重复、缺失、越界、布尔值和小数拒绝 |
| 修改答案沿用旧批改 | 保存最后提交的答案快照；新提交内容改变则清除批改 | 页面修改答案后保存按钮消失，需重新批改 |
| 切换文件导致试卷来源记错 | 试卷绑定生成时的文件名及内容ID | A出题、切B后保存，记录仍属于A |
| 重复保存生成多条记录 | 每次提交生成唯一attempt_key，数据库唯一约束兜底 | 同一提交保存两次只产生一行 |
| SQLite上下文退出未关闭连接 | 事务上下文加finally显式关闭 | Windows临时数据库可正常释放 |
| 每次检索重复分词和统计 | 缓存最近4组语料的BM25预处理 | 语料文本变化即使用新索引 |
| 模型接口等待时间不可控 | 45秒单次请求超时、最多1次自动重试 | 总时长可能超过45秒，不等同整体截止时间 |
| 缺少多轮上下文 | 保留最近3轮已成功问答，支持清空，换资料自动清空 | 模型调用契约测试检查消息数量 |
| 提示词混在长文件中 | 五个system提示词独立为文本文件 | 学生可修改提示词开展A/B实验 |

客观题沿用每题1分，简答题每题5分；简答题4分及以上在错题统计中视为通过。这是练习用规则，不是正式课程成绩标准。

## 数据与启动兼容

- 原有`.env`没有被覆盖，仍兼容`api_key`、`base_url`、`model`简写变量。配置固定从项目根目录读取。
- 不再猜测默认模型ID：必须在`.env`或环境变量中填写服务商当前支持的模型名称。
- 原有`data/learning.db`的记录保留。首次启动若检测到旧表，会先通过SQLite备份接口保存到`data/backups/`，再添加可为空的`attempt_key`列和唯一索引；重复初始化不会重复迁移。旧记录没有内容ID，不伪造补齐。
- 本次测试仅使用临时数据库，未修改用户已有学习记录。备份与迁移会在实际启动应用时执行。
- 本机`.venv`已重新绑定可用的Python 3.12解释器，保留已有依赖。它仍是本机环境，不能复制给学生当作便携环境；学生应运行setup.ps1重建。
- `requirements.txt`固定本次测试使用的直接依赖，并补上原来遗漏的numpy；完整环境另存快照。尚未在干净机器上重新联网安装所有依赖。

## 容量和能力边界

一次最多5个PDF，每个不超过20MB、100页；超限提示拆分。模型输入主要内容限制为30000字符，这是应用容量限制，不是精确token计费。总结、出题仍按选择的页码一次发送，没有实现长文档分层摘要。

问答检查引用编号是否属于本轮资料，不能自动证明“引用真的支持结论”。资料和答案中的指令被提示词标为待分析数据，但提示词不能保证完全防止提示注入。教师仍需人工抽查事实与批改质量。

PDF文本提取和OCR可能本身丢失代码布局。此次修复保证分段不再主动压缩缩进，不保证任意PDF还原出可执行代码；跨片段代码也可能不完整。扫描资料中的代码需要对照原PDF检查。

当前保留BM25关键词检索，尚未增加语义向量模型。多轮历史用于模型理解追问，但检索仍针对当前问题，学生应保留“列表”“异常”等关键词；没有实现指代问题改写。向量检索对照实验可作为课程扩展任务。

五个AI功能是明确任务的模型调用，不是自主规划、选择工具和循环执行的完整Agent。当前未增加用户认证、跨用户数据隔离、共享班级管理和生产部署。start.ps1默认只监听127.0.0.1；不要将本地版直接公开到班级网络。

## 验证说明

运行命令：`.\.venv\Scripts\python.exe -m unittest discover -s tests -v`。

测试包括缩进保留、检索来源、文件签名、题目校验、完整批改、引用编号、输入长度、答案快照、旧表备份迁移、重复保存、PDF文本提取、OCR分支与异常资源释放，以及Streamlit表单交互。模型返回使用测试替身，不消耗API费用；OCR分支使用替身，不代表真实OCR准确率验证。环境检查验证依赖可导入；pip check检查依赖冲突。

正式上课前还应使用实际课程PDF与已配置的模型，人工验收一遍“上传—答疑—出题—批改—保存—计划”，并由另一台学生电脑复现安装步骤。
